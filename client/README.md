# 📦 Gudang Stock AI

**Gudang Stock AI** adalah sistem manajemen inventaris cerdas yang dirancang untuk efisiensi pergudangan modern. Aplikasi ini mengintegrasikan teknologi **AI Vision** dan **Voice Search** untuk mempercepat proses pencarian dan pengelolaan stok barang.

## ✨ Fitur Utama
- 🤖 **AI-Powered Search**: Pencarian stok menggunakan pemindaian gambar (Vision).
- 🎙️ **Voice Command**: Navigasi dan pencarian data melalui perintah suara.
- 📊 **Real-time Analytics**: Dashboard interaktif untuk memantau arus kas dan stok.
- 🔐 **Secure Access**: Proteksi data tingkat tinggi dengan Clerk Authentication.

## 🛠️ Tech Stack
- **Frontend**: Next.js, Tailwind CSS, Redux Toolkit
- **Backend**: Node.js, Express, Prisma ORM
- **Database**: PostgreSQL
